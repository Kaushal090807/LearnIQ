# LearnIQ
LearnIQ is an AI-powered personalized learning and exam preparation platform designed to make studying smarter, more effective, and accessible to every student.
Unlike traditional learning platforms that provide the same study material to everyone, LearnIQ adapts to each student's learning pace, knowledge level, and academic goals.

The platform begins by assessing a student's existing knowledge through diagnostic tests. It identifies strengths, weaknesses, and topics that need improvement. Based on these results, LearnIQ creates a personalized study timetable, recommends targeted practice questions, and provides instant feedback to help students improve continuously.
